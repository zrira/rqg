# Security policy

rqg is an educational and portfolio project. It is feature-complete for its intended scope and is not actively maintained. There are no supported release branches, guaranteed security updates, response SLA, or production-use warranty.

Do not rely on rqg as a complete security boundary. Review the documented [security model](docs/security.md), deployment assumptions, and limitations before experimentation.

If you believe the repository contains a vulnerability, use GitHub's private vulnerability reporting or a private Security Advisory when available. Do not include credentials, personal data, or active third-party exploit details. Reports may not receive a response because the project is not actively maintained.
